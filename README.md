## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox executor tools bundled with a universal loader, designed for Windows desktop users who want a convenient way to manage and run Lua scripts.

### Is XCutors free to use?

Yes, XCutors and all included executors are completely free to download and use. There are no hidden fees or premium tiers.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both 32-bit and 64-bit editions are compatible.

### Can I use multiple executors at the same time?

The universal loader (xcutorsLoader) allows you to install and switch between multiple executors, but you should only run one executor at a time to avoid conflicts.

### How do I update XCutors or the included executors?

Check the GitHub Releases page regularly for new versions. Download the latest release and replace your existing files, or use the built-in update checker in xcutorsLoader.

### My anticomponent flags XCutors as suspicious. Is it safe?

Executors are commonly flagged by anticomponent software due to their nature of injecting code into processes. XCutors is safe to use, but you may need to add an exception in your anticomponent settings.

### Where can I find scripts to use with XCutors?

You can find community-shared scripts on popular Roblox scripting forums, Discord servers, and script repositories. XCutors also includes a built-in script browser for convenience.

### Do I need to disable my anticomponent to use XCutors?

Disabling your anticomponent is not recommended. Instead, add the XCutors folder as an exclusion or exception in your anticomponent software to prevent false positives.

### Can I use XCutors on macOS or Linux?

No, XCutors is designed exclusively for Windows desktop systems. There are no plans for macOS or Linux support at this time.

### How do I report a bug or request a new feature?

You can open an issue on the GitHub repository's Issues page. Please provide detailed information including your OS version, executor used, and steps to reproduce the problem.
